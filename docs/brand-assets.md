Simple Icons is a maintained library of brand marks, not a claim that every technology has its own trademark-owner-published SVG. When an upstream project publishes its own mark, prefer that official asset and follow its current usage policy.

## Poligo interface icons

Functional controls such as rename, delete, folders, terminals, databases and security findings are UI symbols rather than language brands. Do not draw a symbol that imitates a vendor logo for these controls. Use the project's chosen neutral UI icon library or a simple non-branded fallback, with accessible labels for controls that perform actions.

When adding or replacing an icon, retain the upstream proportions and colors, preserve attribution/licence requirements, and verify both template and homepage usage.
